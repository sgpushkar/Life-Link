# Submission Checklist

## Final Pack Checklist

Before uploading the ZIP, confirm the following:

- [ ] Source code is included in the project archive.
- [ ] All required dependencies are documented.
- [ ] Local setup instructions are present and clear.
- [ ] Demo credentials or seed data instructions are included.
- [ ] Architecture overview is included.
- [ ] Problem statement and solution summary are included.
- [ ] Demo flow is documented for judges.
- [ ] Deployment guidance is included.
- [ ] README files are present and readable.
- [ ] The project runs locally with the documented steps.
- [ ] Any required environment variables are listed.
- [ ] Database setup and seeding steps are documented.
- [ ] The ZIP is compressed and named clearly.

## Recommended ZIP Naming

Use a naming convention such as:

```text
LifeLink_Hackathon_Submission.zip
```

or:

```text
LifeLink_Healthcare_Resource_Coordination.zip
```

## Suggested Upload Content

Include the following in the final upload:

- source code,
- package configuration,
- documentation folder,
- README overview,
- setup guide,
- architecture notes,
- demo script,
- any required environment examples.

## Final Review

Before sending the ZIP:

1. open the documentation folder, 
2. confirm instructions are easy to follow,
3. verify the project can be started from a clean environment,
4. check the archive size and file integrity,
5. keep the submission package concise but complete.
