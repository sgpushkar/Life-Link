# LifeLink Hackathon Submission Guide

## Executive Summary

LifeLink is a real-time healthcare inventory and emergency logistics platform built to improve coordination across rural and semi-urban medical facilities. It connects facilities with critical shortages to nearby sources of surplus equipment, blood units, and transport resources while prioritizing patients based on urgency, time sensitivity, and resource scarcity.

## Problem

Healthcare networks frequently face inventory blind spots, communication delays, and poorly prioritized emergency requests. In urgent situations, lack of timely coordination can cause severe delays in treatment and avoidable wastage of valuable resources.

## Solution

LifeLink provides a unified platform for:

- live resource visibility,
- real-time request intake and prioritization,
- blood and donation workflows,
- logistics and handover management,
- low-bandwidth and SMS-compatible operating patterns,
- district-level oversight and analytics.

## Tech Stack

- Frontend: Next.js
- Backend: Node.js + TypeScript + Express
- Database: PostgreSQL + Prisma
- Realtime: Socket-based updates
- Deployment: Vercel + Render

## Demo Narrative

The demo highlights how a facility with a critical shortage can raise an emergency request, how the system ranks the need using urgency logic, how nearby surplus resources are matched, and how transport and handover workflows complete the cycle.

## Setup Overview

1. Install project dependencies
2. Configure environment variables
3. Start the database and seed data
4. Run the project locally
5. Validate the demo workflow
